# Донерим — прототип мобильного приложения

Кликабельный прототип приложения доставки для новой донерной в Астане.
Структура повторяет приложение Додо, стиль свой: тёмная тема, шафраново-жёлтый акцент,
шрифты Unbounded и Onest.

- **Прототип:** откройте `index.html` (или ссылку GitHub Pages этого репозитория).
  Работают меню с фото, сторис, сборка донера, корзина с промокодом `ДОНЕР10` и бонусами,
  оформление, оплата и отслеживание заказа с картой (статусы идут ускоренно).
- **Мокап экранов:** папка `mockup/` — 12 экранов в рамках телефона.

На телефоне прототип можно добавить на экран «Домой» — он откроется как приложение.

Меню, цены и тексты придуманы для примера. Фото взяты из меню ресторанов в ailillu
и подлежат замене на собственные фото заведения. Название и логотип временные.
