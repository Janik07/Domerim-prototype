# Донерим — прототип мобильного приложения

Кликабельный прототип приложения доставки для новой донерной в Астане.
Размеры блоков, цвета, кегли и поведение сняты с приложения Додо, вместо пиццы — донеры.
Фото блюд с вырезанным фоном, тёмная и светлая тема, шрифт Rubik (ближайший открытый аналог Dodo Rounded).

- **Прототип:** откройте `index.html` (или ссылку GitHub Pages этого репозитория).
  Работают меню с фото, сторис, сборка донера, донеркоины с обменом на товары,
  корзина с промокодом `ДОНЕР10`, оформление, оплата и отслеживание заказа с картой
  (статусы идут ускоренно).
- **Тема:** «Профиль → Настройки → Тема приложения» или ссылка с `?theme=light` / `?theme=dark`.
- **Мокап экранов:** папка `mockup/` — 16 экранов в рамках телефона, четыре из них в светлой теме.

На телефоне прототип можно добавить на экран «Домой» — он откроется как приложение.

Меню, цены и тексты придуманы для примера. Фото взяты из меню ресторанов в ailillu
и подлежат замене на собственные фото заведения. Название и логотип временные.
